BundleZone API Reference

Comprehensive guide for integrating with BundleZone (https://bundlezone.shop) in SwiftData Ghana: bundle listings, MTN/Yello beneficiary verification, order submissions, and webhook callbacks.

Base URL https://bundlezone.shop
Auth Header x-api-key: YOUR_API_KEY
Handler Type bundlezone
Recipient Format 0551234567 (10 Digits)
Integration & Usage Rules
Recipient Format Ghana 10-digit local phone number format (e.g. 0551234567).
Capacity Unit Numeric Gigabytes (GB). E.g. 1 for 1GB, 2 for 2GB, 0.5 for 500MB.
Beneficiary Verification Mandatory for MTN / Yello numbers. AT and Telecel bypass verification automatically.
Strict Ordering Rule Only recipients with an explicit VERIFIED status can proceed to order creation.
GET /api/bundles.php

Fetch all available data bundles and exact capacity keys before placing orders. 

curl "https://bundlezone.shop/api/bundles.php" \
  -H "x-api-key: YOUR_API_KEY"
POST /api/beneficiary-check.php

Precheck MTN / Yello recipients. Accepts single or multiple numbers (up to 1,000 numbers per request). Never debits the wallet or creates orders.

Request: 
{
  "network": "MTN",
  "phone_number": "0551234567"
}
Verified Response: 
{
  "success": true,
  "data": {
    "request_id": "REQ-ABC123",
    "network": "MTN",
    "count": 1,
    "results": [
      {
        "phone_number": "0551234567",
        "status": "verified",
        "verification_status": "VERIFIED",
        "verification_request_id": "8fd7a5f4-05ef-4aa8-a44e-8da58f50ef11",
        "can_order": true,
        "retryable": false,
        "estimated_delivery": "30 minutes to 6 hours",
        "message": "The number is verified and ready for ordering."
      }
    ]
  }
}
Status Meaning Ordering Action
VERIFIED Number is approved and active on beneficiary list Safe to order
NOT_VERIFIED Not eligible for ordering Do NOT submit
PENDING Verification decision still in progress Retry later
POST /api/order.php (Single Order)

Submit a single data bundle order for execution.

Payload: 
{
  "mode": "single",
  "network": "MTN",
  "recipient": "0551234567",
  "capacity": 1
}
Successful Accepted Response (HTTP 200): 
{
  "success": true,
  "data": {
    "request_id": "REQ-ABC123",
    "mode": "single",
    "order": {
      "success": true,
      "status": "processing",
      "message": "Order accepted.",
      "estimated_delivery": "30 minutes to 6 hours"
    }
  }
}
Webhooks & Status Callbacks

BundleZone notifies your server when an order changes status via HTTP POST to your registered webhook URL.

Header: Timestamp X-BundleZone-Timestamp: Unix time in seconds. Rejects requests older than 300 seconds.
Header: Signature X-BundleZone-Signature: Format sha256=HMAC_HEX.
Signature Computation Formula: 
signed_payload = X-BundleZone-Timestamp + "." + raw_request_body;
expected_signature = "sha256=" + HMAC_SHA256_HEX(signed_payload, WEBHOOK_SECRET);
Callback Payload Example: 
{
  "event": "order.status_changed",
  "timestamp": "2026-08-17T08:15:00+00:00",
  "data": {
    "order_id": 1842,
    "reference": "BZ-20260817-ABC123",
    "network": "MTN",
    "recipient": "0551234567",
    "capacity": 5,
    "capacity_label": "5GB",
    "price": 19.5,
    "currency": "GHS",
    "status": "completed",
    "source": "api",
    "created_at": "2026-08-17 08:04:31",
    "updated_at": "2026-08-17 08:15:00"
  },
  "client": {
    "api_client_id": 26,
    "client_name": "SwiftData"
  }
}
