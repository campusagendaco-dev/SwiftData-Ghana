Beneficiary Verification API

Integration Documentation for Whitelist Checks

Overview

The SwiftData Ghana Beneficiary Verification API allows integrated resellers and external agents to verify recipient phone numbers against the whitelisting records prior to completing purchases or checkout transactions.

Endpoint

POST https://swiftdatagh.shop/functions/v1/verify-beneficiary

Headers

Header Type Description
Content-Type string Must be set to application/json

Request Body Parameters

Parameter Type Required Description
phone string Yes The recipient's mobile phone number (local format: e.g., 024XXXXXXX or international: 23324XXXXXXX).
network string Yes The mobile network carrier name (e.g., "MTN").

Example Request Payload

{
  "phone": "0244123456",
  "network": "MTN"
}

Example Responses

1. Success (Number is Whitelisted)

If the number exists in the whitelist, the API returns a status 200 with exists: true.

{
  "success": true,
  "exists": true,
  "message": "Number is whitelisted."
}

2. Success (Number is NOT Whitelisted)

If the number is missing from the whitelist, the API returns a status 200 with exists: false and details the error reason.

{
  "success": true,
  "exists": false,
  "error": "Not on beneficiary list",
  "message": "0244123456 is not added to our beneficiary list."
}

Note: Non-MTN numbers do not require whitelisting validation. Submitting any non-MTN carrier (e.g. Telecel or AirtelTigo) will immediately return a success response bypass.
