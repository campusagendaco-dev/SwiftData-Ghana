Anti-Duplicate Order Protection & Idempotency

To prevent accidental duplicate orders caused by client retries, double-clicking, or network lag, BundleZone enforces strict transaction deduplication:

1. Merchant Reference Idempotency Always provide a unique reference (e.g. "API123456789" or UUID) in every single or bulk order payload, and optionally supply the X-Idempotency-Key header.
2. Deduplication Cooldown Window If the same reference or an identical order for the same recipient, network, and package size is submitted within 5–15 minutes, BundleZone blocks duplicate billing and returns the existing order details or code DUPLICATE_ORDER.
3. Downstream Safe Handling When receiving a duplicate response, never fail or cancel the customer's purchase and never cascade to another provider. Keep the order in processing state and check status via /api/status.php or wait for the webhook callback.
Integration & Usage Rules
Networks YELLO (or MTN) for MTN Ghana, Telecel for Telecel, and AT for AirtelTigo.

Webhooks & Status Callbacks

BundleZone notifies your server when an order changes status via HTTP POST to your registered callback URL.

Header: Timestamp X-BundleZone-Timestamp: Unix time in seconds. Rejects requests older than 300 seconds to prevent replay attacks.
Header: Signature X-BundleZone-Signature: Format sha256=HMAC_HEX. Computed over timestamp and raw body.
Expected Response Your server must return an HTTP 200 OK status code with JSON (e.g. {"success": true}) within 25 seconds.
Idempotent Receiver Check if the order is already marked completed before processing to prevent duplicate customer notifications or credits.
Signature Computation Formula: 
signed_payload = X-BundleZone-Timestamp + "." + raw_request_body;
expected_signature = "sha256=" + HMAC_SHA256_HEX(signed_payload, WEBHOOK_SECRET);

Implementation Verification Code Examples: 
import crypto from "node:crypto";

function verifyBundleZoneWebhook(rawBody, timestampHeader, signatureHeader, secretKey) {
  if (!signatureHeader || !secretKey) return false;

  // Replay attack prevention (5 minutes)
  if (timestampHeader) {
    const ts = parseInt(timestampHeader, 10);
    const now = Math.floor(Date.now() / 1000);
    if (Math.abs(now - ts) > 300) return false;
  }

  const signedPayload = timestampHeader ? `${timestampHeader}.${rawBody}` : rawBody;
  const hmac = crypto.createHmac("sha256", secretKey).update(signedPayload).digest("hex");
  const expectedSignature = `sha256=${hmac}`;

  return crypto.timingSafeEqual(
    Buffer.from(signatureHeader.toLowerCase().trim()),
    Buffer.from(expectedSignature.toLowerCase())
  );
}
<?php
$rawBody = file_get_contents('php://input');
$timestamp = $_SERVER['HTTP_X_BUNDLEZONE_TIMESTAMP'] ?? null;
$signature = $_SERVER['HTTP_X_BUNDLEZONE_SIGNATURE'] ?? '';
$secretKey = getenv('BUNDLEZONE_WEBHOOK_SECRET');

if (!$signature || !$secretKey) {
    http_response_code(401);
    exit(json_encode(['error' => 'Missing signature']));
}

// Replay attack protection (5 minutes)
if ($timestamp && abs(time() - (int)$timestamp) > 300) {
    http_response_code(401);
    exit(json_encode(['error' => 'Expired timestamp']));
}

$signedPayload = $timestamp ? "{$timestamp}.{$rawBody}" : $rawBody;
$expectedSignature = 'sha256=' . hash_hmac('sha256', $signedPayload, $secretKey);

if (!hash_equals($expectedSignature, $signature)) {
    http_response_code(401);
    exit(json_encode(['error' => 'Invalid signature']));
}

// Acknowledge receipt
http_response_code(200);
echo json_encode(['success' => true]);
?>
import hmac
import hashlib
import time

def verify_bundlezone_webhook(raw_body: bytes, timestamp: str, signature: str, secret: str) -> bool:
    if not signature or not secret:
        return False

    # Check 5-minute replay window
    if timestamp:
        try:
            ts = int(timestamp)
            if abs(int(time.time()) - ts) > 300:
                return False
        except ValueError:
            return False

    signed_payload = f"{timestamp}.".encode('utf-8') + raw_body if timestamp else raw_body
    computed = "sha256=" + hmac.new(secret.encode('utf-8'), signed_payload, hashlib.sha256).hexdigest()
    
    return hmac.compare_digest(computed.lower(), signature.lower().strip())
